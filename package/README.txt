SentisClientOptimisation 0.2.1 - клиентский плагин Pulsar для Space Engineers: убирает фризы клиента.
Работает на любом сервере, ничего не отправляет на сервер, настроек нет.

Что исправляет: сохранение и загрузку вокселей при подлёте и отлёте, удаление и прогрузку больших гридов,
двигатели и конвейеры больших кораблей, энергию при стыковке и у линий конвейеров, энергию у звука грида и
апгрейд-модулей, сетевые пулы, чертежи проекторов, сборку мусора
при загрузке планет. Кроме того, для самой игры включается серверный сборщик мусора на 4 кучи с бюджетом gen0 32 МБ:
короткие частые сборки вместо длинных (в трейсе простой игры на сборке мусора упал с 15% до 4% времени).

Установка (игра закрыта):
1. Запустите SentisClientOptimisation-<версия>-Setup.exe.
2. Выберите Legacy (.NET Framework 4.8) или Interim (.NET 10). Установленные варианты будут отмечены.
   Если выбранного варианта нет, согласитесь на скачивание Pulsar с официального GitHub.
   Для Interim при необходимости загрузится .NET 10 Desktop Runtime с сайта Microsoft. Установщик:
   - кладёт плагин в каталог Local выбранного режима Pulsar и снимает с него отметку "скачано из интернета";
   - включает плагин в профиле Pulsar;
   - включает серверный GC в конфиге выбранного режима (XML у Legacy, JSON у Interim) (копия прежнего — рядом с конфигом, суффикс .bak-before-gc);
   - кладёт на рабочий стол ярлык "Space Engineers (Pulsar)" с иконкой Sentis: он запускает игру через Pulsar с бюджетом gen0.
3. Запускайте игру этим ярлыком.

Права администратора не нужны. Игра и Pulsar должны быть закрыты во время установки и удаления.

Проверка: в логе игры (%APPDATA%\SpaceEngineers\SpaceEngineers_*.log) есть строки "SentisClientOptimisation: ... on"
и "SentisClientOptimisation: GC: server, ..., gen0 budget 2000000". Если там "workstation" - Pulsar при обновлении
перезаписал свой конфиг: повторите установку EXE.

Удаление: через "Установленные приложения" Windows — убирает плагин, его строку в профиле,
настройку GC и ярлык; посторонние изменения конфига сохраняются. Pulsar и остальные плагины не удаляются.
